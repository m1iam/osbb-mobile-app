# Onboarding

## Як приєднатися до проєкту

Цей документ описує основні кроки для нових учасників команди, необхідні для початку роботи з проєктом «Цифрове ОСББ».

---

## 1. Отримання доступу

Перед початком роботи необхідно отримати доступ до GitHub-репозиторію проєкту.

- Зверніться до адміністратора або власника репозиторію
- Переконайтесь, що маєте доступ до перегляду та редагування

---

## 2. Клонування репозиторію

Склонуйте репозиторій на свій комп’ютер:


git clone https://github.com/m1iam/osbb-mobile-app.git


Перейдіть у папку проєкту:


cd osbb-mobile-app


---

## 3. Встановлення залежностей

Перед запуском необхідно встановити всі залежності:


npm install


або (якщо використовується yarn):


yarn install


---

## 4. Запуск проєкту

Для запуску застосунку виконайте:


npm start


---

## 5. Робота з гілками

Рекомендується працювати в окремих гілках:

- створіть нову гілку для задачі:

git checkout -b feature/назва-задачі


- після завершення роботи створіть Pull Request у гілку `main`

---

## 6. Основні правила

- Дотримуйтесь структури проєкту
- Пишіть зрозумілі назви комітів
- Перед пушем перевіряйте код
- Оновлюйте документацію при внесенні змін

---

## 7. Додатково

- Ознайомтесь з README.md
- Перегляньте ADR-документи в папці `docs/`
- Дотримуйтесь Definition of Done

---

## Контакти

У разі виникнення питань звертайтесь до учасників команди.
