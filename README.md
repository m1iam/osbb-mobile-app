# Цифрове ОСББ

## Опис проєкту
Цифрове ОСББ — це мобільний застосунок для автоматизації управління багатоквартирним будинком, що забезпечує зручну взаємодію між мешканцями та адміністрацією ОСББ.

## Мета проєкту
Метою проєкту є створення інформаційної системи, яка дозволить:
- організувати ефективну взаємодію між мешканцями та адміністрацією;
- автоматизувати обробку заявок;
- проводити голосування;
- забезпечити прозорість фінансової діяльності;
- реалізувати систему сповіщень.

## Основний функціонал

### Для мешканців:
- створення заявок;
- перегляд оголошень;
- участь у голосуваннях;
- перегляд фінансової інформації;
- отримання повідомлень.

### Для адміністратора:
- керування заявками;
- обробка заявок;
- публікація оголошень;
- масові розсилки;
- фінансова звітність;
- контроль виконання документів.

## Технології
- React Native
- Node.js
- MySQL
- SQLite

## Quick Start

1. Клонувати репозиторій:

git clone https://github.com/m1iam/osbb-mobile-app.git


2. Перейти в папку проєкту:

cd osbb-mobile-app


3. Встановити залежності:

npm install


4. Запустити проєкт:

npm start
